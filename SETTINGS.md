# Настройки Mumble RU

## Чаты EVE Online

1. В клиенте EVE включите сохранение журналов чата.
2. Откройте `Start.vbs` → **Открыть чаты EVE**.
3. Нажмите **Папка…**, если папка `Документы/EVE/logs/Chatlogs` не найдена автоматически. Перенос «Документов» в OneDrive поддерживается.
4. В **Выбрать чаты…** отметьте нужные каналы и примените выбор. Переводятся только новые сообщения после запуска; старые журналы не загружаются в переписку.

Каждый канал имеет свою вкладку, историю, счётчик новых сообщений и переключатели:

| Элемент | Действие |
| --- | --- |
| **Вкл перевод** | Автоматический перевод новых сообщений этого канала на русский. При выключении показывается оригинал. |
| **Оповещение** | Разрешение звука только для этой вкладки. |
| **Перевести** | Перевод выделенного текста на русский в отдельном окне. |
| **Ответить ↗** | Ответ по-русски с переводом на язык выделенного исходного текста. |

Для ответа выделите **оригинал**, напишите ответ по-русски, нажмите **Перевести ответ**, проверьте перевод и скопируйте. Вставка и отправка в EVE выполняются вручную через Ctrl+V. Язык определяется по выделенному тексту: при выборе русского перевода ответ останется русским.

## Звуковые оповещения

В **Настройки…** включите общий звук. Добавьте слова или фразы по одному на строку либо через запятую. Нажмите **Проверить звук**, затем **Сохранить**.

- Фильтр не учитывает регистр и ищет целые слова/фразы.
- Для нужной вкладки также должен быть включён переключатель **Оповещение**.
- Без слов фильтра остаётся доступен сигнал о близких системах.
- Одно сообщение вызывает не более одного сигнала; между сигналами выдерживается 2 секунды.

## Исходная система и прыжки

Откройте **Исходная система…**:

- **Определять по локальному журналу игрока** — выберите персонажа, если их несколько. Используются системные события смены Local на русском/английском. Отображаются время и игрок последнего подтверждения. Это последняя известная позиция, пока журнал не обновился.
- **Указать систему вручную** — начните вводить название, выберите подсказку стрелками и Enter либо двойным щелчком. Нажмите **Сохранить**. Ручной режим имеет приоритет над журналом.

Рядом с названиями систем в сообщениях появляются кнопки **Прыжки: N**. Значения: `…` — запрос, `?` — неизвестна исходная система, `—` — маршрут недоступен. Щелчок открывает подробности.

В **Настройки…** включите **Звук: система в 3 прыжках или ближе**, если нужен сигнал при 0–3 прыжках. Учитываются общий звук и звук вкладки; при неизвестной позиции сигнал не подаётся. Пересчёт старых сообщений не озвучивается.

Расстояния получаются через публичный ESI и кэшируются на 5 минут. Учитываются звёздные врата; Ansiblex, червоточины, корабельные прыжки и личный список избегания не учитываются.

## Окна и прозрачность

- Голос и чат открываются в отдельных окнах; положение и размер сохраняются.
- **Поверх окон** включается отдельно для голоса и чата. Для плавающей кнопки — через её меню правой кнопкой.
- В **Настройки… → Прозрачность фона** ползунок задаёт 0–65% прозрачности окна чата.
- **Убрать заливку фона чатов** убирает фон, оставляя текст и кнопки полностью яркими. В этом режиме ползунок отключён.
- Изменения видны сразу; **Сохранить** запоминает их, закрытие без сохранения отменяет предпросмотр.
- **F8** закрепляет/освобождает окно чата и переключает пропуск щелчков. При конфликте горячей клавиши используйте кнопку в окне.
- Плавающая кнопка **Перевод** переключает перевод активной вкладки; её можно перетащить. Меню открывает чат, голос и выбор каналов.
- Закрытие чата скрывает его, обработка и оповещения продолжаются. Закрытие голосового окна завершает всё приложение.

Для оверлея выберите в EVE оконный режим без рамки.

## Голос Mumble

В Mumble откройте **Настройка → Настройки → Плагины**, обновите список и включите **Mumble RU**, включая Audio, если оно показано отдельно. Если DLL занята старым экземпляром, закройте Mumble, повторите установку и откройте его снова.

Переключатель **Переводить речь на русский** управляет распознаванием/переводом; состояние сохраняется. Входящая речь распознаётся локальной моделью Whisper Base на CPU. При первом использовании требуется интернет для скачивания модели (~150 МБ). Имя говорящего берётся из Mumble.

Плагин запускает компаньон при загрузке и закрывает при выгрузке/выходе из Mumble. Ручной запуск через `Start.vbs` также поддерживается. Собственный микрофон не захватывается. Голосовой перевод — текстовые субтитры, без синтеза речи.

## Где хранятся настройки

Параметры сохраняются в `%LOCALAPPDATA%\MumbleRU\settings.json`. Пути запуска плагина — в `HKCU\Software\MumbleRU`. Модель — в папке `models` рядом с приложением.

Эти файлы содержат локальные предпочтения и не нужны другим пользователям. Не добавляйте их и журналы EVE в публичный репозиторий. Для сброса настроек закройте приложение и переименуйте `settings.json`; при следующем запуске будут созданы значения по умолчанию.

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| Чат пуст | В EVE включены журналы, выбрана правильная папка и каналы; дождитесь нового сообщения. Старая история не импортируется. |
| Перевода нет | Включён перевод нужной вкладки, доступен интернет. При сбое сервиса показывается оригинал. |
| Нет звука | Общий звук, звук вкладки, слова фильтра/близкая система и кнопка проверки звука. |
| Прыжки неизвестны | Выберите игрока или задайте исходную систему вручную; проверьте интернет. |
| Нет голоса | Mumble 1.5+ x64, плагин и Audio включены, компаньон запущен; дождитесь новой речи. |
| Приложение перестало запускаться после переноса | Повторите `Install.cmd`, чтобы обновить пути запуска. |
| Ошибка установки Python | Нужен Python 3.11 x64 с tkinter и Python Launcher `py`, а также интернет для зависимостей. |

Для диагностики запустите `.venv\Scripts\python.exe overlay.py` из папки приложения: в консоли будут видны ошибки.
