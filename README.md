# Mumble RU — переводчик Mumble и чатов EVE Online

Приложение для Windows: русские субтитры входящей речи Mumble и автоматический перевод выбранных текстовых каналов EVE Online. Отдельные окна голоса и чата оформлены в стиле EVE.

## Возможности

- Локальное распознавание речи Whisper Base с именем говорящего из Mumble.
- Перевод только выбранных каналов EVE: вкладки, счётчики сообщений, индивидуальные переключатели перевода и звука.
- Перевод выделенного сообщения на русский и подготовка ответа на языке оригинала.
- Добавляемый список слов и фраз для звукового оповещения.
- Кнопки с расстоянием в прыжках рядом с системами; сигнал при 0–3 прыжках.
- Определение исходной системы по Local или ручной ввод с подсказками.
- Независимые окна, прозрачный фон с ярким текстом, отдельные режимы «Поверх окон» и плавающая кнопка.
- Автоматический запуск/закрытие компаньона вместе с плагином Mumble.

Работает без прав администратора сервера, ботов, чтения памяти игры и захвата экрана. Перевод чатов работает и без запущенного Mumble.

## Скачать и установить

Откройте **Releases** справа на странице репозитория и скачайте **MumbleRU-Windows-x64.zip**. Архив исходников GitHub не содержит собранной DLL; для обычной установки используйте архив из релиза.

Требования: **Windows 10/11 x64**, **Python 3.11 x64** с tkinter и Python Launcher (`py`), интернет. Для голосового перевода — **Mumble 1.5+ x64**. Python доступен на [python.org](https://www.python.org/downloads/windows/), Mumble — на [mumble.info](https://www.mumble.info/downloads/).

1. Распакуйте архив в постоянную папку.
2. Запустите **Install.cmd**. Он создаст окружение Python, установит зависимости, скопирует DLL в пользовательскую папку Mumble и сохранит пути запуска в `HKCU\Software\MumbleRU`. Права администратора не требуются.
3. Запустите **Start.vbs**. Для ярлыка на рабочем столе нажмите по нему правой кнопкой → **Отправить → Рабочий стол (создать ярлык)**.
4. Для текста откройте **Открыть чаты EVE → Выбрать чаты…**, отметьте каналы. Убедитесь, что в EVE включено сохранение журналов чата. Переводятся новые сообщения после запуска.
5. Для голоса включите **Mumble RU** и разрешение **Audio** в настройках плагинов Mumble. Обновите список плагинов или перезапустите Mumble. Модель Whisper (~150 МБ) загрузится при первом использовании.
6. Для показа поверх EVE используйте оконный режим без рамки.

После перемещения папки повторите `Install.cmd`. При обновлении закройте приложение и Mumble перед заменой DLL. Пользовательские настройки находятся отдельно от папки приложения.

Альтернативно DLL устанавливается через **Настройки Mumble → Плагины → Установить плагин → MumbleRU.mumble_plugin**, но Python-компаньон и его зависимости всё равно необходимы.

## Настройка и использование

Полная инструкция: **[SETTINGS.md](SETTINGS.md)**.

| Настройка | Где включить |
| --- | --- |
| Каналы для перевода | **Выбрать чаты…** |
| Автоперевод/звук одного канала | **Вкл перевод / Оповещение** внутри вкладки |
| Перевод выбранного сообщения | Выделить текст → **Перевести** |
| Ответ на языке сообщения | Выделить оригинал → **Ответить ↗** → русский ответ → **Перевести ответ** |
| Слова для сигнала и проверка звука | **Настройки…** |
| Позиция игрока/ручная система | **Исходная система…** |
| Сигнал о системе в 0–3 прыжках | **Настройки… → Звук: система в 3 прыжках или ближе** |
| Прозрачность и яркий текст | **Настройки… → Прозрачность фона / Убрать заливку фона чатов** |
| Поверх остальных окон | Переключатель в соответствующем окне; у плавающей кнопки — меню правой кнопкой |

Ответ копируется в буфер обмена; вставку и отправку в EVE выполняет пользователь. Приложение не отправляет сообщения в игру.

Закрытие чата скрывает его, оставляя обработку и оповещения. Закрытие голосового окна завершает приложение. F8 закрепляет/освобождает окно чата. Настройки и положение окон сохраняются между запусками.

## Данные и ограничения

- Аудио распознаётся **локально**. При включённом переводе распознанный текст отправляется Google Translate; ники говорящих не отправляются.
- Текст новых сообщений выбранных каналов отправляется Google при включённом переводе вкладки. Выделенный текст отправляется при открытии перевода/ответа; черновик ответа — по нажатию **Перевести ответ**.
- Используется бесплатный **неофициальный** интерфейс Google Translate, без ключа API. Он может ограничивать запросы или перестать работать; при ошибке автоматического перевода показывается оригинал.
- Маршруты запрашиваются через публичный ESI CCP: передаются ID начальной и конечной систем. Не учитываются Ansiblex, червоточины, корабельные прыжки и личный список избегания.
- Позиция из журнала — последняя подтверждённая, а не гарантированная текущая. При необходимости задайте систему вручную.
- Приложение не записывает аудио, историю переводов и черновики на диск. Краткие буферы, история до 100 сообщений на вкладку и кэши находятся в памяти. Собственные журналы EVE при этом остаются на диске и не изменяются приложением.
- Настройки сохраняются в `%LOCALAPPDATA%\MumbleRU\settings.json`; модель — в папке `models`. Не публикуйте личные настройки и журналы.
- DLL передаёт входящий PCM и имена на `127.0.0.1:47831`, пока компаньон открыт. При выключенном переводе компаньон отбрасывает аудио. При закрытии компаньона захват прекращается. Собственный микрофон не захватывается.
- Whisper работает на CPU: возможна задержка, при перегрузке часть фрагментов пропускается. Названия систем/кораблей и команды могут распознаваться или переводиться неверно. Голосовой результат — субтитры, без озвучки.
- Не поддерживаются Windows ARM/x86, старый Mumble и эксклюзивный полноэкранный режим.

## Разработка и сборка

Исходный код распространяется по [MIT](LICENSE). Использован официальный API плагинов Mumble; лицензия заголовка сохранена в [vendor/LICENSE-Mumble](vendor/LICENSE-Mumble). Каталог систем содержит названия и ID из публичного ESI. Это независимый проект, не официальный продукт CCP Games или Mumble; права на EVE Online и её названия принадлежат правообладателям.

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
# Сборка DLL с Zig 0.15.2:
.\build.ps1 -Zig C:\path\to\zig.exe
# Тесты (закройте запущенный компаньон перед проверкой DLL/loopback):
.venv\Scripts\python.exe -m unittest discover -s tests -v
# Сборка .mumble_plugin и архива для установки:
.venv\Scripts\python.exe package.py
```

Диагностика: `.venv\Scripts\python.exe overlay.py`; демо: добавьте `--demo`. Нативные тесты используют Windows и собранную DLL. Сведения о проверках и известных ограничениях — [VALIDATION.md](VALIDATION.md).
