# Проверено при сборке

## Перевод чатов EVE

- Пройдено 43 теста. Отдельно проверено, что выделенное входящее сообщение переводится на русский без заполнения или отправки ответа.

- Текущий расширенный набор — 42 теста. Проверены необходимость выделения сообщения, открытие окна ответа, перевод на определённый язык (включая zh-CN), русский текст без лишнего запроса и отказ от угадывания языка при некорректном ответе сервиса. Общая тема применена при запуске полного приложения в GUI-проверках.

- Проверены распознавание систем, кнопки расчёта рядом с названиями, ручной приоритет исходной системы, обновление позиции только по системным сообщениям Local и число переходов маршрута. Современный ESI возвращает объект с полем `route`: количество прыжков считается как длина этого списка минус один. На реальном публичном ESI проверен маршрут Jita → Perimeter (1 прыжок), каталог содержит 8490 систем.

- Текущий набор: 37 тестов. Дополнительно проверены подсказки систем, выбор через клавиатуру, числовой счётчик на кнопке, сигналы при 0–3 прыжках, отсутствие сигнала при 4 прыжках и независимое отключение звука в чате.

- Пройдено 26 тестов, включая отдельные вкладки, раздельную историю, отсутствие автоматического переключения, счётчики непрочитанных, совпадения слов/фраз, регистр, границы слов, выключенный звук, пустой фильтр и подавление повторного сигнала для оригинала/перевода. Реальный звук на устройстве проверяется кнопкой «Проверить звук».

- Всего пройдено 22 автоматических теста. Добавлены проверки пропуска старой истории, UTF-16 с разрывом посреди символа/строки, появления нового файла, смены сессии, обрезанного лога, повторов из нескольких персонажей и неполного заголовка. Проверено, что без явного выбора чата переводчик не вызывается; прежний режим «все каналы» преобразуется в пустой выбор.
- Выбор канала, пауза, отдельное отображение автора/перевода и передача переводчику только текста сообщения проверены на синтетических логах. Реальные сообщения пользователя в этих тестах не отправлялись.
- Папка чат-логов обнаружена через системный путь «Документы», перенесённый в OneDrive. Формат заголовков и кодировка UTF-16LE сверены с локальными файлами. Приложение не изменяет эти файлы.

- Компьютер: Windows 10 Pro 19045 x64, установленный Mumble 1.5.939, Python 3.11.
- DLL собрана Zig 0.15.2 для x86_64-windows-gnu, без ошибок и предупреждений компилятора.
- Нативная DLL загружена в тестовом процессе через ctypes. Проверены инициализация, остановка фонового потока, передача PCM и состояний речи, UTF-8-ники через Mumble API, неизменность исходного звукового буфера, стерео → моно, ограничение амплитуды и NaN.
- 13 автоматических тестов прошли: раздельные буферы пользователей, паузы, длинные фразы, смена частоты, тишина, недопустимые пакеты, перевод/кэш и состояние окна. Проверены автоматический запуск/закрытие компаньона настоящей DLL, отсутствие передачи без окна, возобновление после повторного открытия, освобождение mutex при аварийном завершении и обнаружение завершения родительского процесса.
- Реальная модель Whisper Base загружена на CPU. Синтезированная английская фраза распознана, Google вернул русский текст; никаких пользовательских записей в проверке не использовалось.
- Проверен полный тестовый путь: экспорт DLL → UDP loopback → сборка фразы → локальный Whisper → Google Translate → текст в оверлее с ником Fleet Commander.
- DLL скопирована в пользовательский каталог плагинов Mumble. Активация плагина в настоящем клиенте и проверка на реальном голосовом канале пользователем ещё нужны. Соединение Mumble автоматически не перезапускалось.
- Рендер окна поверх настоящей EVE и глобальная клавиша F8 в игре не проверены: текущий механизм захвата окон Windows в этой сессии возвращает timeout. Управление окном, обновление текстов и переключение распознавания проверены кодом приложения.
